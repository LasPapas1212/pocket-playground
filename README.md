# Pocket Playground

Tiny browser games. No sign-up, just play.

**Play it:** https://laspapas1212.github.io/pocket-playground/

50 quick games in one page:

- **Reaction:** Reaction Time, Quick Draw, Go / Stop, Lightning Tiles, Bonk, Color Rush, Stop the Clock, Rhythm Tap
- **Aim:** Aim Trainer (easy / medium / hard), Balloon Pop, Tracker, Fruit Slice, Shooting Gallery, Shrinking Dots, Precision
- **Arcade:** Click Frenzy, Stacker, Dodge, Slither, Sky Hopper, Hop Runner, Brick Breaker, Paddle Duel, Fruit Catch, Space Blaster, Lane Racer, Sky Jumper
- **Puzzle:** Tile Merge, Sweeper, Number Rush, Odd One Out, Higher or Lower, Lights Out, Slide Puzzle, Math Sprint, Maze Run
- **Memory:** Echo Pads, Pair Up, Grid Recall, Number Memory
- **Word:** Type Sprint, Five Letters, Word Scramble, Balloon Words
- **2 Player:** Tic-Tac-Toe, Connect Four, Paddle Battle, Reflex Duel. Play a friend on the same computer, or a bot (easy, medium, hard, extreme).
- **Chill:** Bubble Wrap, Paint Splat

Settings (gear button) cover sound and volume, theme, animations, confetti, screen shake, keyboard hints, and resetting your data. Best scores are saved in your browser only.

## Run it locally

It's a single `index.html` with no build step. Open it in a browser, or serve the folder with any static web server.
