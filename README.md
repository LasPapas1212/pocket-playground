# Pocket Playground

Tiny browser games. No sign-up, just play.

**Play it:** https://laspapas1212.github.io/pocket-playground/

29 quick games in one page:

- **Reaction:** Reaction Time, Quick Draw, Go / Stop, Lightning Tiles, Bonk
- **Aim:** Aim Trainer (easy / medium / hard), Balloon Pop, Tracker, Fruit Slice
- **Arcade:** Click Frenzy, Stacker, Dodge, Slither, Sky Hopper, Hop Runner, Brick Breaker, Paddle Duel
- **Puzzle:** Tile Merge, Sweeper, Number Rush, Odd One Out, Higher or Lower
- **Memory:** Echo Pads, Pair Up
- **Word:** Type Sprint, Five Letters
- **2 Player:** Tic-Tac-Toe, Connect Four, Paddle Battle. Play a friend on the same computer, or a bot (easy, medium, hard, extreme).

Best scores are saved in your browser only.

## Run it locally

It's a single `index.html` with no build step. Open it in a browser, or serve the folder with any static web server.
